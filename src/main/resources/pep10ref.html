Macros

Macros are written with a leading @, for example @DECO x,d. Most are defined in stdmacro.pep and are available to every program. The stack macros (DUP, DDUP, DROP, DDROP, NIP, DNIP, SWAP, DSWAP) are defined in stack.pep. Add .INCLUDELIB "stack" before the first use of any of them, since macros must be defined before they are used. LIBC and MALLOC define routines, so place them after the halt sequence. MALLOC must be the last statement in the program.

Name Modes Effect
SNOP i No operation
DECI d, n, s, sf, x, sx, sfx Reads a decimal integer from input and stores it at Operand
DECO i, d, n, s, sf, x, sx, sfx Writes Operand to output as a decimal integer
HEXO i, d, n, s, sf, x, sx, sfx Writes Operand to output as 4 hexadecimal digits. Flags unaffected.
STRO d, n, s, sf, x, sx, sfx Writes the null-terminated ASCII string starting at Operand to output. Flags unaffected.
DUP none Duplicates the top word on the stack: SUBSP 2, then copies the old top word into the new top. Clobbers A. Requires .INCLUDELIB "stack" before first use.
DDUP none Duplicates the top 32-bit value (two words, high word at the lower address) on the stack. Clobbers A. Requires .INCLUDELIB "stack" before first use.
DROP none Discards the top word on the stack (ADDSP 2). Requires .INCLUDELIB "stack" before first use.
DDROP none Discards the top 32-bit value on the stack (ADDSP 4). Requires .INCLUDELIB "stack" before first use.
NIP none Discards the second word on the stack, keeping the top one. Clobbers A only. Requires .INCLUDELIB "stack" before first use.
DNIP none Discards the second 32-bit value on the stack, keeping the top one. Clobbers A only. Requires .INCLUDELIB "stack" before first use.
SWAP none Swaps the top two words on the stack. Clobbers A and X. Requires .INCLUDELIB "stack" before first use.
DSWAP none Swaps the top two 32-bit values on the stack. Clobbers A and X. Requires .INCLUDELIB "stack" before first use.
ASLAn, ASLXn, ASRAn, ASRXn,
ROLAn, ROLXn, RORAn, RORXn		 none Repeat the corresponding single-step shift or rotate n times, for n from 2 to 5 (for example ASLA3 is three ASLA). Flags are those left by the last repetition.
CHARI d, n, s, sf, x, sx, sfx Reads one character from charIn and stores it in the byte at Operand (LDBA charIn,d then STBA Operand). Clobbers A.
CHARO i, d, n, s, sf, x, sx, sfx Writes the low byte of Operand to charOut (LDBA Operand then STBA charOut,d). Clobbers A.
PUSH i, d, n, s, sf, x, sx, sfx Pushes the word Operand on the stack (LDWA Operand, STWA −2,s, SUBSP 2). Clobbers A.
XCHGA d, n, s, sf, x, sx, sfx Exchanges A with the word at Operand, using 4 bytes of stack temporaries. Not atomic; the SWAPA instruction does the same in one step. For the stack-relative modes, Operand is counted from SP after the temporaries are allocated.
XCHGX d, n, s, sf, x, sx, sfx Exchanges X with the word at Operand, using 6 bytes of stack temporaries. A is preserved; N and Z come from the new X. Not atomic; the SWAPX instruction does the same in one step. The same note about stack-relative modes applies.
XNORA i, d, n, s, sf, x, sx, sfx A ← NOT (A XOR Operand)
XNORX i, d, n, s, sf, x, sx, sfx X ← NOT (X XOR Operand)
MALLOC none Defines a simple heap allocator, malloc, and the heap itself. Must be the last statement in the program. To allocate, load the number of bytes into A and CALL malloc,i; X returns a pointer to the new block. Memory is never freed. Place it after the halt sequence.
LIBC none Defines printf. After CALL printf,i, the format string pointer is at 2,s and the arguments follow it on the stack. In the format string, %H prints an argument in hexadecimal, %D in decimal, %S as a string (the argument is a pointer to a null-terminated string), %C as a character, and %% prints a percent sign. Any other placeholder prints an error message and powers off. Place it after the halt sequence.

Special Memory Locations

  • FFF7,FFF8: Trap handler
  • FFF9,FFFA: Boot address
  • FFFB,FFFC: Initial stack pointer
  • FFFD: Character input (charIn)
  • FFFE: Character output (charOut)
  • FFFF: Power off (pwrOff)

Operation Cycle

PC ← Mem[FFF9]
SP ← Mem[FFFB]
do
    IR[0:7] ← Mem[PC], PX ← 0
    PC ← PC + 1
	if IR[0:7] is prefix
	    PX ← IR[0:7]
		IR[0:7] ← Mem[PC]
		PC ← PC + 1
    if PX,IR[0:7] is dyadic
        IR[8:23] ← Mem[PC]
        PC ← PC + 2
    Execute the instruction in PX,IR
while not power off && instruction was legal

Directives

.ASCII "string"
insert the ASCII character code bytes for the string
.BLOCK n
insert a block of n zero bytes
.BYTE x
insert a single byte given by x (low byte if x is a word)
label: .EQUATE x
associate the label with the value x in the symbol table
.WORD x
insert a two-byte word given by x
The following are intended for OS-level code
.ALIGN 1|2|4|8
advance the current position to a multiple of the given number
.DEFMACRO name[, nargs]
define a macro @name with the given number of arguments ($1, $2, ...)
.ENDMACRO
terminate a macro definition
.EXPORT sym
add the symbol to the export list
.INCLUDE "file"
assemble the contents of the given file at the current location
.INCLUDELIB "resource"
assemble the contents of the given resource library at the current location
.INPUT sym
mark the symbol as memory-mapped input
.ORG addr
shift this section so that the given address is the current position
.OUTPUT sym
mark the symbol as memory-mapped output
.SCALL sym
generate a system call macro for the given symbol
.SECTION "name", "permissions"
start a named section with the given permissions (read/write/execute/zero)
